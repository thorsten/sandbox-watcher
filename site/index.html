Sandbox Watcher

One window for everything happening in your running MaibornWolff Sandbox containers.

Download from GitHub Releases

Unsigned builds for macOS, Windows and Linux. Free and open source, MIT.

Who is running where

Every sandbox container across Docker, Podman and Apple container, grouped by project, with the agent sessions inside: Claude Code, Codex, OpenCode, Pi or a plain shell.

What they reach

Blocked and allowed destinations per container, read from sandbox's own firewall, proxy and DNS logs. A header stat shows blocked requests of the last five minutes.

What they cost

CPU and memory sparklines, network and disk I/O, container logs with follow and filter, and every mount classified as project, persisted, runtime or extra.

The few things you want to do

Stop a container or all of them, with a list of the sessions it interrupts. Open the project in your terminal or file manager. Copy names, paths and ready-made commands.

Lives in the tray

A menu bar icon with a summary per project, and notifications when a session starts, a sandbox stops unexpectedly, requests get blocked in bursts, or a stale container shows up.

Private by design

Talks only to your local container runtime. Never reads environment variable values, only their names. Sends nothing anywhere.

Install

Builds are not signed yet, so each OS asks once for trust.

macOS
Open the .dmg, drag the app to Applications, then run once: 
xattr -dr com.apple.quarantine "/Applications/Sandbox Watcher.app"
or right-click the app and choose Open. Apple silicon and Intel builds are separate.
Windows
Run the .msi or the -setup.exe. If SmartScreen appears, choose More info, then Run anyway. Works with Docker Desktop, Rancher Desktop and Podman.
Linux
Use the .deb, .rpm or .AppImage. The AppImage needs chmod +x. Your user must be allowed to use the Docker or Podman socket.

Requirements: a running Docker, Podman or Apple container, and at least one project set up with sandbox init.

Build it yourself

git clone https://github.com/thorsten/sandbox-watcher
cd sandbox-watcher
pnpm install
pnpm tauri dev

Rust stable, Node 24 and pnpm are required. See the README and the milestone plan.
