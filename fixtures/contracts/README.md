# Rust/TypeScript contract fixtures

Generated by `crates/sandbox-core/tests/contracts.rs` and
`src-tauri/src/contracts.rs`: every type that crosses the Tauri bridge,
serialised with every enum variant and every optional field both empty and
set. `enums.json` lists every enum's wire values.

`pnpm check:contracts` assigns these documents to the types in
`src/types.ts` and lets `tsc` reject any mismatch. Do not edit by hand;
regenerate with

```sh
SANDBOX_WATCHER_UPDATE_CONTRACTS=1 cargo test -p sandbox-core --test contracts
```

and commit the result together with the Rust and TypeScript change. See
`docs/CHECKS.md`.
